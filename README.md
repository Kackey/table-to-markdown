# 表 → Markdown 変換

Notion・Numbers・Googleスプレッドシート・Excel でコピーした表を貼り付けると、Markdown の表に変換してワンクリックでコピーできるツールです。

`index.html` 1ファイルだけで動きます。ビルドやサーバーは不要で、ブラウザで開くだけで使えます。

## 使い方

1. `index.html` をブラウザで開く
2. 各アプリで表のセル範囲を選んでコピーする
3. 「貼り付け」欄に貼り付ける
4. 「コピー」ボタンを押す

## 機能

- タブ区切りテキスト（スプレッドシート系アプリのコピー形式）に対応
- クリップボードに HTML の表が含まれている場合はそちらを優先して読み取り（Notion などで有効）
- セル内の改行は `<br>`、`|` は `\|` に自動変換
- 列ごとの配置（既定・左・中央・右）を切り替え可能
- 全角文字を考慮して列幅を揃える（オフも可）
- 1行目を見出しにするかどうかを選択可能
- 貼り付けと同時に自動コピーするオプション

## Git での管理

```sh
cd table-to-markdown
git init
git add .
git commit -m "表 → Markdown 変換ツールを追加"
```

GitHub Pages で公開すれば、ブックマークからすぐ開けるようになります。
